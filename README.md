# 焊接大师 · 第一阶段手感原型

一块 PCB、两个电阻、一颗红色 LED，共六个通孔焊点。纯静态中文网页游戏，使用 Canvas 2D 绘制工作台、元件、烙铁、焊锡和烟雾，无构建步骤，无外部依赖或 CDN。

## 运行

在项目目录执行：

```bash
python3 -m http.server 8765
```

浏览器打开 `http://localhost:8765`。也可以直接打开 `index.html`，音效需要首次交互后启动。

本次测试发现 IPv4 的 8765 端口被另一个项目占用，为避免影响它，使用：

```bash
python3 -m http.server 8765 --bind ::1
```

对应地址为 `http://[::1]:8765`。不需要安装 npm 包，不会请求外部资源。

## 操作

- 移动鼠标，将烙铁尖端放到编号焊盘的亮圈中。
- 按住左键加热，温度接近 300°C 时保持左键，同时按右键或空格送锡。
- 锡量达到约 70–100% 后，松开所有按键。低于 180°C 后自动结算，通常约五秒可以完成一个完美焊点。
- 低于 250°C 时，送锡只会顶住，不会增加锡量。
- 移开烙铁也会停止接触加热。长时间按住会使焊盘过热；锡量超过 140% 会形成球状焊点，LED 相邻焊盘还可能连锡。
- 手机先点选或拖动到焊盘，再用屏幕上的“按住加热”和“按住送锡”按钮配合操作，支持双指同时按住。
- 顶栏可切换声音、重新开始。六个焊点结算后显示本轮成绩和逐点品质，可再次练习。

## 实现

`index.html` 提供中文 HUD、触屏按钮和总结弹窗；`style.css` 提供深色工作台布局及屏幕适配；`game.js` 实现绘制、输入、温度/润湿模拟、结算和合成音效。

温度使用带接触热惯性的指数响应；热源目标 415°C，松手和移开后指数冷却。熔化温度为 250°C，送锡速度约每秒 53%。品质同时考虑送锡时温度、峰值温度、总加热时间、锡量和润湿程度。完美焊点呈内凹银色锥形；冷焊呈灰色颗粒；过量呈球形；过热会冒烟、焦黑、翘起。

采用 `requestAnimationFrame`，静态电路板绘制到离屏缓存；动态烟雾有数量上限；处理窗口缩放、设备像素比（最高按 2 倍渲染）、页面失焦和输入释放。音效由 WebAudio 噪声滤波和振荡器合成，无音频文件。离开页面会释放操作并静音。

只读调试接口：

```js
window.__game.getState()             // 焊点状态副本、分数、连击、输入
window.__game.getJointPosition(0)    // 焊点的浏览器视口坐标
window.__game.reset()                // 清空本轮
```

调试接口不提供直接设置温度、锡量或品质的能力，测试使用真实鼠标、键盘和触摸事件。

## 已知不足

这是单板手感原型，热传导与焊锡流动采用简化模型，画面为程序绘制的风格化效果，不是参考图那样的照片级材质。没有返修、拆件、多关卡或存档。手机竖屏焊盘较小，横屏或较大屏幕操作更舒适；小屏会收起元件托盘。触控已用浏览器模拟验证，尚未覆盖各型号真机；合成音效已接入并验证初始化，但未进行实体音响听感验收。
